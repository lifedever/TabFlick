TabFlick

扩展安装说明

TabFlick Bridge 扩展暂未上架 Chrome 应用商店，需要通过开发者模式安装，一次装好长期使用。

  1. 下载并解压扩展包

    下载 TabFlick-Extension.zip，双击解压得到 TabFlick-Extension 文件夹。建议把它放到一个不会误删的位置（如「文稿」）—— Chrome 会持续从这个文件夹加载扩展，删掉文件夹扩展就失效了。

    下载扩展包

  2. 打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 回车，或菜单 → 扩展程序 → 管理扩展程序。

  3. 开启开发者模式

    页面右上角有「开发者模式」开关，打开它，页面顶部会多出一排按钮。

  4. 加载扩展

    点「加载已解压的扩展程序」，选择第 1 步解压出的 TabFlick-Extension 文件夹。列表里出现 TabFlick Bridge 即安装成功。

  5. 确认连接

    保持 TabFlick 应用运行，菜单栏图标变亮、第一行显示「已连接」即两端接通。之后按住 ⌃ 点 ⇥ 就能唤出切换器。

升级说明：TabFlick 应用发新版时，如果发版说明提到扩展有更新，下载新的扩展包解压覆盖原文件夹，然后在 chrome://extensions 点击 TabFlick Bridge 卡片上的刷新按钮（↻）即可。
