切换器 · ⌃⇥

回到上一个标签，而不是旁边那个

Chrome 的 ⌃⇥ 按标签栏顺序走。TabFlick 让它按你用过的顺序走。

  • 来回切换稳定。 再按一次就回到出发的标签；按住时只移动游标，中途经过的不算用过。
  • 网页缩略图。 靠页面样子认标签，不用读截断的标题。
  • 键盘、方向键、鼠标都行。 ⌃⇧⇥ 反向，按住时方向键移动，或直接点卡片。
  • 按窗口分开。 只列当前窗口的标签，每个窗口有自己的顺序。设置里可以关。

搜索面板 · ⌘E

要找的东西，打几个字就到

标签、最近关闭、书签、历史记录、收藏的文件夹、已装的 App，都在同一个框里。

  • Tab 换范围。 全部、标签、搜索、历史记录、书签、最近关闭、文件夹、应用依次切，顺序和开关在设置里定。
  • 中文用拼音也能搜。 全拼和首字母都认，mnjt 能找到「蒙牛集团」。
  • 没找到就搜网页。 用浏览器自己的默认引擎，也可以加 GitHub、YouTube 这类站内搜索。
  • 在别的 App 里也能用。 按 ⌥Space，搜所有浏览器的标签，选中就切过去。没输入时列的是最近用过的标签和 App，回车回到上一件事。

还有这些

置顶常驻

置顶的标签重启浏览器后自动回来，停在最后看的那页。

自动清理闲置标签

12 小时、24 小时或 7 天没用过就关掉；置顶、在放声音的、标签组里的不动。默认关。

菜单栏标签列表

状态栏菜单按窗口列出所有标签和最近关闭的，点一下切过去。

收藏的文件夹

把常用目录收在菜单栏，选 Finder、终端或编辑器打开。

全局切换器

在浏览器之外按 ⌃⇥，按浏览器分组列出所有标签。默认关。

出问题不会吞键

扩展没连上时，⌃⇥ 交回给 Chrome 自带的切换，不会按了没反应。

安装

一个 App 加一个浏览器扩展，两分钟装好。

1

装 App

下载 DMG，把 TabFlick 拖进「应用程序」。第一次打开如果提示无法验证开发者，在「应用程序」里右键 TabFlick 选「打开」。

下载 App
2

装扩展

解压扩展包，打开 chrome://extensions，开启开发者模式，点「加载已解压的扩展程序」选中文件夹。

下载扩展 图文步骤
3

给辅助功能权限

第一次启动会打开「系统设置」的「辅助功能」页，TabFlick 已经在列表里，打开它的开关，App 会自动重启。菜单栏图标变亮就是连上了。

扩展要标签、书签、历史记录、图标、搜索这几项权限，数据只交给本机的 TabFlick，不联网。升级后 Chrome 提示新权限时点允许，再重新加载扩展。日志在 ~/Library/Logs/TabFlick/tabflick.log。
为什么要一个 App 加一个扩展 
┌─────────────────────────┐         ┌──────────────────────────┐
│  Chrome Extension (MV3) │  ws://  │  Swift Helper            │
│                         │◄───────►│                          │
│  · tabs / bookmarks     │  :41573 │  · CGEventTap  (keys)    │
│  · history / favicons   │         │  · NSPanel     (panels)  │
│  · captureVisibleTab    │         │  · MRU state machine     │
└─────────────────────────┘         └──────────────────────────┘
扩展读不到键盘。 Chrome 33 起扩展就不能绑定带 Tab 的快捷键，所以要一个原生进程接管 ⌃⇥。
原生进程读不到标签。 标签、书签、历史记录和切换都要走 Chrome 的扩展 API，所以要一个扩展。两边通过本机 WebSocket 连在一起。
